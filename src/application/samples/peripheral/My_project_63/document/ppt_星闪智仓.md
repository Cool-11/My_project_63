## Slide 04 -- 技术选型：为什么是NearLink？

### 标题：NearLink vs BLE vs Zigbee -- 为什么选择星闪

| 对比维度 | BLE 5.0 | Zigbee 3.0 | **NearLink SLE** |
|----------|---------|------------|------------------|
| 连接速度 | ~6ms | ~30ms | **~3ms** |
| 功耗 | 中等 | 低 | **极低（标签端电池寿命更长）** |
| 抗干扰 | 一般 | 较好 | **优秀（SLE专用频段）** |
| 最大连接数 | 7-20 | 65000 | **理论无上限** |
| 国产自主 | 否 | 否 | **是（华为主导，300+企业参与）** |
| 生态成熟度 | 高 | 中 | **快速增长中** |
| 标签芯片成本 | ~5元 | ~8元 | **~6元（BS21E）** |

### 选择NearLink的核心理由

1. **国产自主可控**：星闪是华为主导的国产近距通信标准，300+企业参与生态建设，不受国外技术封锁影响
2. **低功耗长续航**：SLE协议针对IoT场景优化，标签端电池寿命可达2-3年
3. **快速连接**：3ms级连接建立速度，适合频繁扫描的仓储场景
4. **成本可控**：BS21E芯片集成SLE+MCU，单芯片方案，BOM成本低
5. **政策支持**：国家重点支持国产通信标准，符合信创要求

## Slide 06 -- 核心创新点 1：NearLink协议落地

### 标题：创新点一 -- 首次将NearLink SLE应用于仓储电子标签

### 技术突破

**问题**：星闪（NearLink）是2023年才发布的新协议，目前主要应用于音频（耳机）、车钥匙等场景，在仓储管理领域的应用尚属空白。

**我们的工作**：
1. **协议适配**：自定义SSAP服务结构（Service 0xFF00 / Property 0xFF01），实现标签数据的读写和通知
2. **广播解析**：解析Manufacturer Data（AD Type=0xFF），提取标签ID、库存、电量等12字节业务数据
3. **连接管理**：实现扫描→连接→配对→SSAP发现→CCCD写入→命令收发的完整链路
4. **参数对齐**：与BS21E端同步连接间隔(62.5ms)、监督超时(5s)等参数，解决断联问题
5. **字节序统一**：全链路大端序（Big-Endian），消除跨设备数据解析错误

### 关键协议设计

```
SSAP Write 命令 (WS63→BS21E):
  0x00 停止寻物 | 0x01 寻物 | 0x02 盘点 | 0x10 更新数量 | 0x20 写入标签ID

SSAP Notify 响应 (BS21E→WS63):
  0x82 盘点回复(9字节) | 0xA0 绑定成功(3字节) | 0xAF 绑定失败(3字节)

广播Payload (12字节):
  magic(4B) + tag_id(2B) + qty(2B) + status(1B) + battery(1B) + seq(2B)
```

## Slide 07 -- 核心创新点 2：三端协同架构

### 标题：创新点二 -- WS63+ESP32+BS21E 三端解耦架构

### 架构创新

传统IoT方案通常将所有功能集中在单一MCU上，导致代码耦合度高、调试困难、扩展性差。

**我们的方案**：将系统拆分为三个独立端，各司其职：

| 端 | 芯片 | 职责 | 优势 |
|----|------|------|------|
| **网关端** | WS63 | SLE通信+业务决策+WiFi上云 | 强大的网络能力 |
| **交互端** | ESP32 | 触摸屏UI+4G透传 | 丰富的外设和显示能力 |
| **标签端** | BS21E | 数据存储+声光寻物 | 超低功耗，电池供电 |

### 解耦设计

- **通信协议标准化**：WS63↔BS21E用SSAP二进制协议，WS63↔ESP32用UART JSON
- **回调桥接**：main.c作为唯一耦合点，注册所有跨模块回调
- **单向依赖**：uart_vision→business_logic→sle_network，禁止反向引用
- **统一主循环**：10ms轮询驱动所有模块，零多线程，零竞态

### 代码规模

| 模块 | 代码量 | 职责 |
|------|--------|------|
| shared_protocol | ~300行 | 二进制协议编解码 |
| sle_network | ~980行 | SLE扫描/连接/SSAP |
| uart_vision | ~350行 | UART JSON收发 |
| business_logic | ~715行 | 业务决策+映射表+NV |
| cloud_storage | ~675行 | WiFi+MQTT+离线缓存 |
| main.c | ~282行 | 主循环+回调桥接 |
| **合计** | **~3300行** | **完整系统** |

## Slide 08 -- 核心创新点 3：低成本电子标签

### 标题：创新点三 -- 成本降低70%的仓储电子标签方案

### 成本对比

| 方案 | 单标签成本 | 100个标签总成本 | 适用场景 |
|------|-----------|----------------|---------|
| 电子墨水屏标签 | 80-150元 | 8000-15000元 | 大型商超/高端仓储 |
| BLE电子标签 | 50-80元 | 5000-8000元 | 中型仓库 |
| **BS21E星闪标签** | **<15元** | **<1500元** | **中小型仓库/便利店** |

### 为什么能做到低成本？

1. **单芯片方案**：BS21E = SLE射频 + Cortex-M0 MCU + Flash，无需外挂主控
2. **极简硬件**：蜂鸣器+LED+纽扣电池，无屏幕、无复杂外设
3. **NV持久化**：tag_id和MAC掉电保持，无需额外EEPROM
4. **批量生产**：芯片级集成，BOM成本可控

### 标签端功能

| 功能 | 实现 |
|------|------|
| 数据广播 | 持续广播tag_id+qty+status+battery（25ms间隔） |
| 声光寻物 | 收到0x01命令后蜂鸣器+LED响15秒，自动停止 |
| 库存同步 | 收到0x10命令后更新qty，广播实时反映 |
| 身份绑定 | 收到0x20命令后NV持久化tag_id，掉电不丢失 |
| 低功耗 | 无连接时进入Standby/Sleep，电池寿命2-3年 |

## Slide 09 -- 核心创新点 4：云边端一体化

### 标题：创新点四 -- 端侧采集 + 边缘决策 + 云端管理

### 三层数据流

```
端侧层 (BS21E标签)
  │ 广播: tag_id, qty, status, battery
  ▼
边缘层 (WS63网关)
  │ 业务决策: 入库/盘点/寻物/出库
  │ 本地存储: NV Flash映射表(32个标签)
  │ 离线缓存: 16条MQTT消息自动缓存
  ▼
云端层 (ThingsKit)
  │ 数据上报: v1/devices/me/telemetry
  │ 远程下发: v1/devices/me/rpc/request/+
  │ 可视化: Dashboard实时监控
```

### 云边协同亮点

| 特性 | 说明 |
|------|------|
| **离线优先** | 网络断开时本地正常工作，数据自动缓存 |
| **自动重连** | WiFi断连→自动回退→重连后自动刷新缓存 |
| **MQTT QoS1** | 关键数据QoS1确保至少送达一次 |
| **NV持久化** | 映射表+MQTT配置掉电不丢失 |
| **远程下发** | 云端可通过RPC远程控制网关（如触发盘点） |

    "qty": 50,

## Slide 10 -- 业务流程

### 标题：四大核心业务场景

### 场景一：入库绑定

```
用户操作：在ESP32触摸屏选择"入库" → 选择区域(A1) → 输入物品名(Type-C)
系统流程：
  1. WS63扫描发现新标签(tag_id=0)
  2. 分配tag_id → SLE发送0x20绑定命令
  3. BS21E确认(0xA0) → 写入NV持久化
  4. 同步库存数量(0x10) → 更新本地映射表
  5. MQTT上报云端 → 触摸屏显示"绑定成功"
耗时：<3秒
```

### 场景二：智能盘点

```
用户操作：在ESP32触摸屏点击"盘点"
系统流程（两种模式）：
  被动扫描模式（秒级）：
    WS63扫描所有BS21E广播 → 提取tag_id+qty → 更新映射表
  主动查询模式（分钟级）：
    逐个连接BS21E → 发送0x02 → 收取0x82回复(含最新qty+电量)
  → 生成盘点报告 → MQTT上报云端
耗时：秒级(被动) / 2-3分钟(主动)
```

### 场景三：声光寻物

```
用户操作：在ESP32触摸屏输入物品名或选择标签 → 点击"寻物"
系统流程：
  1. 查映射表定位标签位置(zone)
  2. SLE连接目标标签 → 发送0x01寻物命令
  3. BS21E蜂鸣器+LED响15秒 → 触摸屏显示位置(A1-05)
  4. 自动停止，status恢复0x00
耗时：<2秒
```

### 场景四：出库管理

```
用户操作：在ESP32触摸屏选择物品 → 点击"出库"
系统流程：
  1. 从映射表删除该标签
  2. NV持久化更新
  3. MQTT上报出库信息
  4. 触摸屏显示"出库成功"
耗时：<1秒
```
