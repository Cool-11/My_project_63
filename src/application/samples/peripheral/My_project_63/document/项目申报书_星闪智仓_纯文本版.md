# 基于WS63主控的星闪视觉双模仓储管理系统

## 项目摘要

本项目设计并实现了一种基于国产星闪（NearLink）协议的低成本、易部署智能仓储电子标签管理系统。系统采用WS63网关芯片作为核心控制器，通过SLE协议连接BS21E电子标签，结合ESP32触摸屏实现人机交互，并通过WiFi+MQTT协议实现云端数据管理。相比传统BLE/Zigbee方案，本系统标签成本降低70%以上，盘点效率提升95%，部署周期缩短90%。系统实现了入库绑定、智能盘点、声光寻物、出库管理四大核心业务场景，支持离线缓存和自动重连，具有国产自主、降本增效、工程完整三大核心优势。

**关键词：** 星闪协议；智能仓储；电子标签；WS63；云边端一体化

---

## Abstract

This project designs and implements a low-cost, easy-to-deploy intelligent warehouse electronic label management system based on the domestic NearLink protocol. The system uses the WS63 gateway chip as the core controller, connects BS21E electronic labels through the SLE protocol, combines ESP32 touchscreen for human-computer interaction, and realizes cloud data management through WiFi+MQTT protocol. Compared with traditional BLE/Zigbee solutions, this system reduces label costs by over 70%, improves inventory efficiency by 95%, and shortens deployment cycles by 90%. The system implements four core business scenarios: inventory binding, intelligent inventory counting, acoustic-visual item finding, and inventory management, supporting offline caching and automatic reconnection, with three core advantages: domestic independence, cost reduction and efficiency improvement, and engineering completeness.

**Keywords:** NearLink protocol; intelligent warehouse; electronic label; WS63; cloud-edge-terminal integration

## 一、项目背景与意义

### 1.1 行业背景

中国仓储管理市场规模超过1000亿元，其中中小仓库占比超过70%。然而，已实现数字化管理的比例不足20%，核心矛盾在于数字化需求旺盛，但现有方案成本过高、部署过于复杂。

传统仓储管理面临四大痛点：
1. 人工盘点效率低：依靠纸质标签+条码枪逐个扫描，一次盘点耗时数小时
2. 纸质标签易出错：手写/打印标签，人工录入系统，出错率高达3-5%
3. 电子标签成本高：现有BLE/Zigbee电子标签单价50-100元，中小仓库用不起
4. 系统部署复杂：传统IoT方案需要专用网关+服务器+软件，部署周期长

### 1.2 技术背景

星闪（NearLink）是华为主导的国产近距通信标准，300+企业参与生态建设，具有以下优势：
- 国产自主可控：不受国外技术封锁影响
- 低功耗长续航：SLE协议针对IoT场景优化，标签端电池寿命可达2-3年
- 快速连接：3ms级连接建立速度，适合频繁扫描的仓储场景
- 成本可控：BS21E芯片集成SLE+MCU，单芯片方案，BOM成本低

### 1.3 项目意义

1. 技术意义：首次将NearLink SLE协议应用于仓储电子标签领域，推动国产通信标准在工业场景的落地
2. 经济意义：标签成本降低70%以上，使中小仓库数字化成为可能
3. 社会意义：符合国家信创要求，推动国产芯片和协议的应用

## 三、技术方案

### 3.1 系统架构

系统采用三端解耦、模块化、事件驱动的架构设计：

整体架构分为三层：

第一层：ESP32触摸屏（用户界面/操作终端）
- 功能：入库选择、盘点触发、寻物定位
- 通信：UART 115200bps (JSON)

第二层：WS63网关固件（单线程）
- uart_vision模块：JSON收发、命令分发
- business_logic模块：映射表+决策引擎、入库/盘点/寻物
- sle_network模块：SLE扫描/连接、SSAP读写
- cloud_storage模块：WiFi+MQTT、离线缓存
- 通信方式：回调桥接（main.c）

第三层：云平台（ThingsKit）
- 功能：远程监控/下发
- 通信：WiFi + MQTT

### 3.2 核心技术

#### 3.2.1 NearLink协议适配

- SSAP服务结构：Service 0xFF00 / Property 0xFF01
- 广播解析：解析Manufacturer Data（AD Type=0xFF），提取标签ID、库存、电量等12字节业务数据
- 连接管理：扫描→连接→配对→SSAP发现→CCCD写入→命令收发的完整链路
- 参数对齐：连接间隔(62.5ms)、监督超时(5s)等参数同步
- 字节序统一：全链路大端序（Big-Endian），消除跨设备数据解析错误

#### 3.2.2 三端协同架构

网关端（WS63芯片）：
- 职责：SLE通信+业务决策+WiFi上云
- 优势：强大的网络能力

交互端（ESP32芯片）：
- 职责：触摸屏UI+4G透传
- 优势：丰富的外设和显示能力

标签端（BS21E芯片）：
- 职责：数据存储+声光寻物
- 优势：超低功耗，电池供电

#### 3.2.3 事件驱动架构

- 单线程协作：禁止多线程，10ms轮询调度，零竞态
- 中断极简：中断只做数据搬运，业务逻辑全在主循环
- 安全编码：strncpy_s/memcpy_s，NULL检查，cJSON校验

### 3.3 关键协议设计

SSAP Write 命令（WS63→BS21E）：
- 0x00 停止寻物
- 0x01 寻物
- 0x02 盘点
- 0x10 更新数量
- 0x20 写入标签ID

SSAP Notify 响应（BS21E→WS63）：
- 0x82 盘点回复(9字节)
- 0xA0 绑定成功(3字节)
- 0xAF 绑定失败(3字节)

广播Payload（12字节）：
- magic(4字节) + tag_id(2字节) + qty(2字节) + status(1字节) + battery(1字节) + seq(2字节)

## 四、创新点

### 4.1 NearLink协议落地

首次将星闪SLE协议应用于仓储电子标签领域，实现以下技术突破：
1. 协议适配：自定义SSAP服务结构，实现标签数据的读写和通知
2. 广播解析：解析Manufacturer Data，提取12字节业务数据
3. 连接管理：实现完整的10步连接流程
4. 参数对齐：解决断联问题
5. 字节序统一：消除跨设备数据解析错误

### 4.2 三端协同架构

WS63+ESP32+BS21E三端解耦架构，各司其职：
- 通信协议标准化：WS63与BS21E用SSAP二进制协议，WS63与ESP32用UART JSON
- 回调桥接：main.c作为唯一耦合点，注册所有跨模块回调
- 单向依赖：uart_vision→business_logic→sle_network，禁止反向引用
- 统一主循环：10ms轮询驱动所有模块，零多线程，零竞态

### 4.3 低成本电子标签

基于BS21E单芯片方案，成本降低70%：
1. 单芯片方案：BS21E = SLE射频 + Cortex-M0 MCU + Flash，无需外挂主控
2. 极简硬件：蜂鸣器+LED+纽扣电池，无屏幕、无复杂外设
3. NV持久化：tag_id和MAC掉电保持，无需额外EEPROM
4. 批量生产：芯片级集成，BOM成本可控

### 4.4 云边端一体化

端侧采集+边缘决策+云端管理：
- 离线优先：网络断开时本地正常工作，数据自动缓存
- 自动重连：WiFi断连→自动回退→重连后自动刷新缓存
- MQTT QoS1：关键数据QoS1确保至少送达一次
- NV持久化：映射表+MQTT配置掉电不丢失
- 远程下发：云端可通过RPC远程控制网关

## 六、应用场景

### 6.1 入库绑定

用户操作：在ESP32触摸屏选择"入库" → 选择区域(A1) → 输入物品名(Type-C)

系统流程：
1. WS63扫描发现新标签(tag_id=0)
2. 分配tag_id → SLE发送0x20绑定命令
3. BS21E确认(0xA0) → 写入NV持久化
4. 同步库存数量(0x10) → 更新本地映射表
5. MQTT上报云端 → 触摸屏显示"绑定成功"

耗时：3秒以内

### 6.2 智能盘点

用户操作：在ESP32触摸屏点击"盘点"

系统流程（两种模式）：
被动扫描模式（秒级）：WS63扫描所有BS21E广播 → 提取tag_id+qty → 更新映射表
主动查询模式（分钟级）：逐个连接BS21E → 发送0x02 → 收取0x82回复(含最新qty+电量)

耗时：秒级(被动) / 2-3分钟(主动)

### 6.3 声光寻物

用户操作：在ESP32触摸屏输入物品名或选择标签 → 点击"寻物"

系统流程：
1. 查映射表定位标签位置(zone)
2. SLE连接目标标签 → 发送0x01寻物命令
3. BS21E蜂鸣器+LED响15秒 → 触摸屏显示位置(A1-05)
4. 自动停止，status恢复0x00

耗时：2秒以内

### 6.4 出库管理

用户操作：在ESP32触摸屏选择物品 → 点击"出库"

系统流程：
1. 从映射表删除该标签
2. NV持久化更新
3. MQTT上报出库信息
4. 触摸屏显示"出库成功"

耗时：1秒以内
