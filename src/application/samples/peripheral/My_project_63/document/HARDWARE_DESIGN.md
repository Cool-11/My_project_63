## 一、系统总体硬件架构

### 1.1 系统组成

本系统由 **网关主控板** 和 **电子货架标签** 两大部分组成：

| 部件 | 核心芯片 | 数量 | 角色 |
|------|---------|------|------|
| 网关主控板 | WS63 SoC (EVB) | 1 | 系统大脑：SLE网络管理 + WiFi上云 + 业务逻辑 |
| 视觉感知模组 | ESP32-S3-N13R8 CAM (OV5640) | 1 | 视觉识别 + AI推理 |
| 串口触摸屏 | 淘晶驰 TJC T1 4.3寸 (3.3V) | 1 | 人机交互界面 |
| 4G通信模组 | 广和通 L610 | 1 | 备选上云通道 |
| 电子货架标签 | 第三方SLE模组 (BS21e方案) | N个 | 库位标识 + 声光寻物 |

### 1.3 硬件方案

**方案：WS63 EVB开发板 + PCB底板 + 外壳**

WS63 EVB开发板已集成以下资源，**无需额外设计**：
- WS63 SoC最小系统 (芯片+晶振+电源)
- 2.4GHz PCB天线 (SLE/WiFi/BLE共用)
- 8MB Flash
- **Type-C供电口** (板载LDO，5V→3.3V)
- 调试串口 (UART0)

**需要设计的**：
- PCB底板：连接各模块的转接板
- 外壳：3D打印外壳，露出屏幕、摄像头、Type-C口

#### 2.4.4 供电设计

- **供电方式**: 从WS63 EVB排针取3.3V + GND
- **峰值电流**: 约2A (4G发射时，持续时间很短)
- **电源滤波**: 在L610 VCC引脚附近放置：
  - 100μF 电解电容 (储能，应对峰值电流)
  - 10μF 瓷片电容 (中频滤波)
  - 100nF 瓷片电容 (高频滤波)

#### 2.4.5 L610引脚定义

> **详见L610数据手册** (已提供给硬件开发人员)

实际需要连接的引脚：

| L610引脚 | 功能 | 连接目标 |
|----------|------|---------|
| TX | UART TX | → ESP32-S3 GPIO20 (RX) |
| RX | UART RX | ← ESP32-S3 GPIO19 (TX) |
| VCC | 电源正极 | 3.3V (从EVB取电) |
| GND | 电源负极 | GND |

#### 2.4.6 L610硬件设计要点

1. **SIM卡座**: L610模块自带，插入nano-SIM卡即可
2. **4G天线**: 必须外接4G天线，否则无法正常通信
3. **电源滤波**: VCC附近放 100μF + 10μF + 100nF 电容
4. **UART**: 115200bps，连接到ESP32的GPIO19/20
5. **开机时序**: L610上电后约5-10秒才能响应AT指令

## 四、电源设计

### 4.1 供电方案

**WS63 EVB开发板自带Type-C供电口**，板载LDO将5V转为3.3V。所有模块统一从EVB取电。

```
  Type-C 5V ──────→ ┌──────────────────┐
                     │   WS63 EVB       │
                     │   (板载LDO)      │
                     │   5V → 3.3V      │
                     └────────┬─────────┘
                              │ 3.3V + GND (通过排针引出)
            ┌─────────────────┼─────────────────┐
            │                 │                 │
     ┌──────┴──────┐   ┌─────┴─────┐   ┌──────┴──────┐
     │ ESP32-S3    │   │  串口屏   │   │  L610 4G   │
     │ N13R8 CAM   │   │ (3.3V    │   │ (3.3V+GND) │
     │ (3.3V+GND)  │   │  +GND)   │   │            │
     └─────────────┘   └──────────┘   └─────────────┘
```

**供电说明**:
- WS63 EVB的Type-C口为所有模块供电
- ESP32-S3-N13R8 CAM: 从WS63 EVB排针取3.3V + GND
- 串口屏: 从WS63 EVB排针取3.3V + GND
- L610: 从WS63 EVB排针取3.3V + GND
- 所有模块共地 (GND统一)

**L610峰值电流处理**:
- L610 4G发射时峰值电流约2A，持续时间很短 (毫秒级)
- 在L610 VCC引脚附近放置大容量电容缓冲：
  - **100μF 电解电容** (储能，应对峰值电流)
  - **10μF 瓷片电容** (中频滤波)
  - **100nF 瓷片电容** (高频滤波)
- 电容可以在峰值电流时释放能量，避免电压跌落

### 4.2 电流估算

| 模块 | 典型电流 | 峰值电流 | 供电电压 |
|------|---------|---------|---------|
| WS63 (WiFi+SLE) | 150mA | 350mA | 3.3V (EVB板载LDO) |
| ESP32-S3 (待机) | 80mA | 150mA | 3.3V (模组LDO) |
| ESP32-S3 (AI推理) | 300mA | 600mA | 3.3V (模组LDO) |
| 串口屏 (背光最亮) | 100mA | 200mA | 3.3V |
| L610 (待机) | 30mA | 50mA | 3.3V |
| L610 (4G发射) | 500mA | 2000mA | 3.3V |
| **总计 (WiFi场景)** | **660mA** | **1300mA** | - |
| **总计 (4G场景)** | **810mA** | **3000mA** | - |

### 4.3 电源设计注意事项

1. **EVB供电能力**: WS63 EVB的Type-C口可提供5V/3A，板载LDO输出3.3V
2. **统一供电**: 所有模块从EVB排针取3.3V
3. **L610峰值处理**: L610峰值电流2A，在VCC附近放大电容 (100μF+10μF+100nF)
4. **GND共地**: 所有模块必须共地，否则通信会出错

## 五、PCB底板设计

### 5.1 方案概述

采用 **PCB底板** 方案：设计一块2层PCB底板，各模块通过对应的接口连接到底板上，底板内部走线完成所有电气连接。

### 5.2 各模块物理接口

| 模块 | 准确型号 | 接口形式 | 底板对应接口 | 连接方式 |
|------|---------|---------|-------------|---------|
| 网关主控 | WS63 EVB开发板 | 排针 (2.54mm) | 排母 2×20Pin | 插拔式 |
| 视觉感知 | ESP32-S3-N13R8 CAM | 排针 (2.54mm) | 排母 2×20Pin | 插拔式 |
| 串口屏 | 淘晶驰 TJC T1 4.3寸 | **XH2.54-4P插头** | **XH2.54-4P座子** | 插拔式 |
| 4G模组 | 广和通 L610 | 待确认 | 待确认 | 待确认 |

### 5.3 排针类型说明

模块上的排针可能是**直插**或**弯脚**的，底板需要对应设计：

```
方案A: 直插排针 (模块竖立)
┌──────────┐
│  模块     │
│          │
└──┬┬┬┬┬┬──┘
   ││││││ ← 直插排针 (垂直向下)
   ││││││
═══╧╧╧╧╧╧═══ ← PCB底板

方案B: 弯脚排针 (模块平放) ← 推荐！
┌──────────┐
│  模块     │
└──────────┘
   └┘└┘└┘└┘ ← 弯脚排针 (90度弯脚)
═══════════ ← PCB底板
```

**注意事项**:
- 需要确认WS63 EVB和ESP32-S3-N13R8 CAM的排针是直插还是弯脚
- 如果是直插排针，模块会竖立在底板上
- 如果是弯脚排针，模块会平放在底板上
- **弯脚排针更省空间**，适合装进外壳
- 如果模块是直插排针，可以自己换成弯脚排针 (需要焊接)

**串口屏连接示意**:

串口屏背面的XH2.54插头是**水平方向**的，和屏幕表面平行，可以直接插入底板：

```
外壳前面板 (从外面看)
┌─────────────────────────────────────┐
│                                     │
│   ┌─────────────────────────────┐   │
│   │      串口屏显示 (朝外)       │   │
│   │      触摸操作区域            │   │
│   └─────────────────────────────┘   │
│                  │                  │
│                  │ ← XH2.54插头     │
│                  │   (水平方向)     │
│                  ▼                  │
│   ═══════════════════════════════   │ ← PCB底板
│                                     │
│   [WS63 EVB]  [ESP32]  [L610]      │
│                                     │
└─────────────────────────────────────┘
外壳后面板 (Type-C口朝外)
```

**安装方式**:
1. 串口屏贴在外壳前面板内侧 (显示面朝外)
2. XH2.54插头水平向后插入底板的XH2.54座子
3. 底板上的其他模块 (WS63 EVB、ESP32、L610) 平放在底板上
4. Type-C口从外壳后面板露出

### 6.3 外壳设计注意事项

1. **串口屏**: 贴在前面板内侧，显示面朝外，XH2.54插头水平向后插入底板
2. **摄像头**: 开口需保证无遮挡，建议加透明亚克力保护盖
3. **Type-C口**: 从后面板露出，开口需预留插拔空间
4. **天线**: 外壳侧面或顶部留天线窗口，避免金属遮挡
5. **散热**: 底部留散热孔 (ESP32-S3 AI推理时发热较大)
