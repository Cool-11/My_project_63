# shared_protocol 模块说明（分析版）

## 模块定位
- 该模块是三端协议唯一事实源，只维护跨端字段定义、长度约束、字节序约束和版本约束。
- 该模块不做业务运算，不依赖硬件驱动。

## 重点约束
- 协议结构体必须保持 1 字节对齐，避免填充导致空口不兼容。
- 约束结构体字段含义：magic、tag_id、qty、status、battery、seq。
- 变更协议字段时必须同步评估 ESP32、WS63、BS21e 三端兼容性。

## 日志与可观测性要求
- 模块初始化打印协议版本和结构体长度。
- 每次打包/解包前后打印字段摘要（避免打印过长原始缓冲）。
- 解包失败必须打印失败原因（长度不符、magic 不符、CRC/校验失败）。

## 审查清单
- 空指针检查：输入输出缓冲区不能为空。
- 长度检查：严格等于协议长度才允许解包。
- 边界检查：qty、battery、status 取值范围必须受限。

## 验证思路（串口）
1. 上电后确认协议版本日志和结构体长度日志出现。
2. 注入一帧合法数据，确认解析成功日志和字段摘要。
3. 注入 magic 错误/长度错误数据，确认拒绝并打印错误分支日志。
4. 注入边界值数据（qty=0、battery=100），确认通过并输出预期日志。
