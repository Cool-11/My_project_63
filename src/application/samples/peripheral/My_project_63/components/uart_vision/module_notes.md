# uart_vision 模块说明（分析版）

## 模块定位
- 该模块负责 WS63 与 ESP32 的串口交互，承载视觉结果上报与 UI 指令请求。
- 协议采用 JSON 文本 + 换行符作为帧结束。

## 重点约束
- 只做通信与协议解析，不做库存加减业务决策。
- 收到一包 JSON 后必须进行字段完整性校验和命令白名单校验。
- 发送响应必须包含状态字段，避免上层等待无反馈。

## 日志与可观测性要求
- 串口初始化、收包、解包、命令分发、应答发送均打印。
- 异常分支（超时、非 JSON、字段缺失）必须打印错误类型。
- 对大包和畸形包打印截断摘要，避免刷屏阻塞。

## 审查清单
- 空指针检查：接收缓存和输出对象。
- 长度检查：防止越界与粘包误解析。
- 命令校验：仅允许约定 cmd 进入业务层。

## 验证思路（串口）
1. 发送合法 inbound_req，确认解析成功和分发日志。
2. 发送非法 JSON，确认被拒绝且打印错误原因。
3. 发送缺字段命令，确认被拒绝且打印字段缺失日志。
4. 连续发送多条命令，确认无粘包误判和顺序错乱。
