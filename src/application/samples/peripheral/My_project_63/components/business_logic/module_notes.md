# business_logic 模块说明（分析版）

## 模块定位
- 该模块只做库存计算、盘点差异判断、库区分配决策。
- 该模块不直接访问 UART/SLE/文件系统，必须通过接口调用其他模块。

## 重点约束
- 输入输出对象必须显式定义，禁止隐式全局状态耦合。
- 所有库存运算要具备幂等思维，避免重复消息导致重复扣减。
- 异常输入（负数、超大值、未知物料）必须返回明确错误码。

## 日志与可观测性要求
- 每次业务决策打印输入摘要、决策结果、原因码。
- 关键状态迁移（入库、出库、盘点异常）必须打印。
- 幂等命中场景要单独打印，便于复盘。

## 审查清单
- 空指针检查：请求对象和结果对象。
- 数值边界检查：qty 不能下溢或溢出。
- 一致性检查：决策前后库存快照可追踪。

## 验证思路（串口）
1. 输入正常入库请求，确认库存增加日志正确。
2. 输入正常出库请求，确认库存扣减日志正确。
3. 重复发送同一序列请求，确认幂等命中日志出现。
4. 输入异常数量，确认拒绝并打印错误码。
