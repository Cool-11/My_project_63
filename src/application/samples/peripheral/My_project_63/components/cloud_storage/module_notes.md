# cloud_storage 模块说明（分析版）

## 模块定位
- 该模块负责 4G 上云通道和本地文件系统离线缓存。
- 该模块对上提供“写入记录/补传记录/查询状态”，不直接参与 SLE 控制。

## 重点约束
- 网络不可达时必须落盘，不允许静默丢数据。
- 恢复在线后按先入先出补传，并保留失败重试计数。
- 存储写入必须考虑掉电一致性（先写临时，再原子切换）。

## 日志与可观测性要求
- 初始化、挂载、上云成功、上云失败、落盘成功、补传成功/失败都打印。
- 每条记录打印唯一追踪 ID，便于跨模块关联。
- 重试路径打印退避时间和重试次数。

## 审查清单
- 空指针检查：记录对象、文件句柄、网络句柄。
- 返回值处理：文件 I/O 与网络发送必须逐项检查。
- 容量保护：达到阈值时要有明确告警和处置策略。

## 验证思路（串口）
1. 断网场景下写入数据，确认落盘日志出现。
2. 恢复网络后，确认按队列顺序补传并打印成功日志。
3. 制造发送失败，确认重试退避日志与最终状态可见。
4. 模拟存储满，确认告警日志和降级处理日志出现。
