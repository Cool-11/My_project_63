# sle_network 模块说明（分析版）

## 模块定位
- 该模块负责 WS63 侧 SLE 扫描、广播匹配、连接、配对、SSAP 发现与收发调度。
- 该模块不做库存业务规则，只提供网络状态与收发能力。

## 已确认真实 API 参考（来自 sle_63_host_scan_report.md）
- 扫描初始化主链路：sle_set_seek_param() + sle_start_seek()
- 扫描回调：seek result 回调中执行目标过滤
- 连接动作：sle_connect_remote_device()
- 广播侧关联 API：sle_set_announce_param()、sle_set_announce_data()
- 回调注册封装参考：SleAnnounceSeekRegisterCallbacks()

## 重点约束
- 广播载荷按样例上限 251 字节规划。
- 63 角色按 G 侧（发起连接）建模，21e 按 T 侧（广播侧）建模。
- 每次 write 动作或超时后必须断开连接，释放底层句柄和空口资源。

## 日志与可观测性要求
- 初始化、开始扫描、停止扫描、连接开始、连接成功/失败、配对成功/失败、断开均打印。
- 每个底层 API 调用前后都打印返回码。
- 超时和重试路径必须打印重试计数与原因。

## 审查清单
- 空指针检查：回调参数和上下文句柄。
- 返回值处理：所有 SLE API 返回值必须分支处理。
- 状态机检查：禁止在未连接状态下发送 write。

## 验证思路（串口）
1. 启动后检查扫描启动日志，确认参数打印完整。
2. 让 21e 发广播，检查匹配日志是否命中目标。
3. 检查连接、配对、MTU、服务发现日志顺序是否完整。
4. 触发一次写操作后，确认断开日志出现且句柄释放日志出现。
5. 人为制造目标丢失，确认超时重试与失败退出日志可追踪。
